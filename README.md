# Nodo — Realtime Talent Network

Nodo is a realtime talent network for hackathons. It connects builders, designers, and thinkers through AI-powered matching, skill validation, and collaborative workspaces.

## What it does

1. **Discover** — Browse active hackathons and subscribe to participate
2. **Graph** — Visualize the live network of people, teams, and skills with force-directed rendering
3. **Match** — AI recommends compatible teammates based on skills and team needs (via LLM chat)
4. **Teams** — Create teams, apply to join, accept/reject applications
5. **Board** — Realtime brainstorming workspace (drag cards, vote, select winner)
6. **Challenges** — Skill validation quizzes generated by AI (Kahoot-style, realtime)

## Architecture

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Frontend   │────▶│   Backend    │────▶│   PGlite     │
│  React/Vite  │     │   Hono/Node  │     │  (Postgres)  │
└──────┬───────┘     └──────┬───────┘     └──────────────┘
       │                    │
       │    WebSocket       │
       ◀────────────────────┘
       │     Portal SDK
       │
  Realtime events:
  - Graph patches (new person, team created, match suggested)
  - Board updates (card moved, voted, winner)
  - Challenge questions (revealed, leaderboard, ended)
  - Presence (who's online)
```

### Portal (Realtime)

[Portal](https://useportal.co) handles all WebSocket communication:

| Channel | Purpose | Events |
|---------|---------|--------|
| `event-{eventId}` | Public graph + feed | person.upserted, team.created, team.member_joined, match.suggested |
| `team-{teamId}` | Private team comms | application.created, board.card_created, board.vote_cast |
| `challenge-{teamId}-{challengeId}` | Live quiz | question_revealed, leaderboard_update, challenge.ended |

The frontend subscribes via `@portalsdk/react` hooks. Token auth via `POST /v1/portal/token`.

### AI Integration

- **Matchmaker** — Backend agent analyzes skills/needs and creates `suggested` edges in the graph
- **Challenge Generator** — LLM generates skill-specific quiz questions
- **Chat Assistant** — `POST /v1/_debug/chat` answers questions about the graph ("Who should I team up with?")

## Running locally

### Prerequisites

- Node.js >= 22
- pnpm 9+

### Setup

```bash
# Install dependencies
pnpm install

# Build shared contracts
pnpm --filter @nodo/contracts build
```

### Start the database (Terminal 1)

```bash
pnpm db:local
```

This starts PGlite (embedded Postgres) on port 55432. Keep this terminal open.

### Migrate and seed (Terminal 2)

```bash
pnpm db:migrate
pnpm db:seed
```

### Start the backend (Terminal 2)

```bash
pnpm dev:api
```

Runs on `http://localhost:8080`.

### Start the frontend (Terminal 3)

```bash
pnpm dev:web
```

Runs on `http://localhost:5173`.

## Environment

Copy `apps/api/.env.example` to `apps/api/.env` and fill in:

| Variable | Required | Purpose |
|----------|----------|---------|
| `DATABASE_URL` | Yes | `postgresql://postgres:postgres@127.0.0.1:55432/postgres` for local |
| `PORTAL_SECRET` | For realtime | Portal secret key |
| `PORTAL_PUBLIC_KEY` | For realtime | Portal public key (used by frontend) |
| `LLM_API_KEY` | For AI features | Groq API key |
| `JWT_PRIVATE_KEY` | Yes | RS256 PEM key for auth tokens |

## Key Features

### Light/Dark Mode
Full theme support across all pages. Default is light mode. Persists to localStorage.

### Force Graph
Custom canvas rendering with:
- Pulsing halos on person/team nodes
- Animated dash lines for AI match suggestions
- Floating skill nodes
- Search highlighting with cyan ring
- Click to view node details in modal

### Team Panel
Slide-out drawer with team info, members (online/offline), pending applications, and board access.

### AI Chat
Floating chat bubble on the graph that talks to the backend LLM for match recommendations.

## API Endpoints (key ones)

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/v1/events` | List hackathons |
| POST | `/v1/events/:id/subscription` | Subscribe to event |
| GET | `/v1/graph?eventId=` | Graph snapshot |
| POST | `/v1/teams` | Create team |
| POST | `/v1/teams/:id/applications` | Apply to team |
| POST | `/v1/applications/:id/resolve` | Accept/reject |
| GET | `/v1/teams/:id/board` | Board cards |
| POST | `/v1/teams/:id/board/cards` | Create card |
| POST | `/v1/_debug/chat` | AI chat |
| POST | `/v1/portal/token` | Get Portal auth token |
